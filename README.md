# 🏏 Playgrounds & Tribute Pages

A collection of responsive web tribute pages built for fun and practice, celebrating memorable sports victories and cultural heritage while sharpening frontend web development skills.

---

## 📌 Projects Directory

| Project | Description | Tech Used | Folder |
| :--- | :--- | :--- | :--- |
| **City of Joy Tribute** | A visual tribute exploring the culture, essence, and landmarks of Kolkata. | HTML5, CSS3 | [`city-of-joy-tribute/`](./city-of-joy-tribute) |
| **India T20 World Cup 2024** | Commemorating Team India's historic 2024 ICC Men's T20 World Cup championship run. | HTML5, CSS3 | [`india-t20-worldcup-2024-tribute/`](./india-t20-worldcup-2024-tribute) |
| **KKR IPL 2024 Champions** | Celebrating Kolkata Knight Riders' title-winning campaign in IPL 2024. | HTML5, CSS3 | [`kkr-ipl-2024-tribute-page/`](./kkr-ipl-2024-tribute-page) |

---

## 🛠️ Concepts Practiced

- **Semantic HTML5:** Clean sectioning with `<header>`, `<main>`, `<article>`, and `<figure>`.
- **Responsive Layouts:** Flexbox and CSS Grid for mobile-to-desktop fluid views.
- **Card & Banner Design:** Visual presentation with hero images, badges, and typography.
