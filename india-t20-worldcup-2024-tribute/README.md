# 🇮🇳 India T20 World Cup 2024 – Tribute Page

A cinematic tribute website celebrating India's undefeated 2024 T20 World Cup victory.

## 🏆 Overview

This project captures the emotion, dominance, and legacy of India's historic 2024 T20 World Cup triumph.  
Designed with a dark championship theme, gradient hero text, and interactive player spotlight cards.

## ✨ Features

- Hero section with gradient “TEAM INDIA” styling
- Player spotlight cards with hover effects
- Grayscale-to-color image transitions
- CSS variables for easy theme customization
- Responsive grid layout
- Clean typography and spacing system
